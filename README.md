# Trade & Ahead – Stock Market Clustering 

## Overview
Applied unsupervised learning (K-Means, Hierarchical Clustering) to group stocks based on financial indicators for use in portfolio diversification strategies.

## Key Insights
- Four unique clusters discovered with varied volatility and return characteristics
- Visualized stock clusters using Power BI dashboard

## Tools Used
- Python (Scikit-learn, Seaborn)
- K-Means, Dendrograms, PCA
- Power BI (Dashboard Visualization)

## Deliverables
- Feature scaling and dimensionality reduction
- Clustering model evaluation
- Investment recommendations based on clusters

## Recommendation
Use clusters to diversify portfolios, reduce risk exposure, and create custom strategies by segment.
